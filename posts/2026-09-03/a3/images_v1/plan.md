## 이미지 01 — "AI 자동화, 사실은 네 층위로 나뉜다" 아래
- 용도: 개념 비교 인포그래픽 (본문의 4유형 비교 표를 시각화)
- 무엇을 그리는가: 상단 소제목 "AI 자동화, 네 가지 유형". 가로로 4개 카드(챗봇형/코파일럿형/워크플로우 자동화(RPA성)/독립 에이전트), 각 카드는 색상 헤더 바 + 아이콘 + "하는 일" 라벨/텍스트 + "예시" 라벨/텍스트로 구성. 텍스트는 초안 표에 있는 그대로만 사용:
  - 챗봇형 · 하는 일: 질문에 답변 · 예시: 인사·구매 규정 안내
  - 코파일럿형 · 하는 일: 문서 작업 보조 · 예시: 오피스·독스 옆 초안 작성
  - 워크플로우 자동화(RPA성) · 하는 일: 규칙 기반 처리 · 예시: 티켓 분류·담당자 연결
  - 독립 에이전트 · 하는 일: 조건 인지 후 자율 행동 · 예시: 조건 성립 시 스스로 실행
  카드 행 아래에 화살표 하나 + "사람 개입 많음 → 스스로 판단하는 비중 커짐"이라는 방향성 라벨만 표시(구체적 비율 수치 없음, 초안 문장 그대로의 정성적 표현만 사용)
- 비율/viewBox: `0 0 1200 800`
- alt 텍스트: 챗봇형, 코파일럿형, 워크플로우 자동화, 독립 에이전트 네 가지 AI 자동화 유형을 하는 일과 예시로 비교한 표
- 파일명: 01.svg

## 이미지 02 — "챗봇·코파일럿과 진짜 '에이전트'를 가르는 기준" 아래
- 용도: 개념도
- 무엇을 그리는가: 중앙에 "에이전트" 아이콘(별/로봇 심볼). 그 주변에 여러 업무 시스템을 뜻하는 일반적 박스 3개(문서 시스템 / 데이터베이스 / 커뮤니케이션 도구 — 초안에 특정 시스템명이 없으므로 일반 범주명만 사용)를 배치하고 "MCP"라고 라벨 붙인 연결선으로 에이전트와 이음. 에이전트에서 사람 아이콘(승인자) 쪽으로 말풍선 화살표를 그려 "이걸 실행해도 될까요?" 텍스트, 사람 아이콘 옆에 체크 표시 + "승인" 라벨로 응답을 표현. 하단에 작은 라벨로 "평가·감사" "운영자 관리"를 아이콘 없이 텍스트 배지로만 추가(초안에 언급된 요건이므로 유지, 새로운 수치·조건 추가 없음)
- 비율/viewBox: `0 0 1200 800`
- alt 텍스트: AI 에이전트가 MCP로 여러 업무 시스템에 연결돼 실행 전 인간의 승인을 구하는 개념도
- 파일명: 02.svg

## 이미지 03 — "내 업무엔 뭐가 맞을까 — 판단은 이렇게" 아래
- 용도: 프로세스/분기 흐름 다이어그램
- 무엇을 그리는가: 왼쪽에 업무 성격을 나타내는 4개의 조건 텍스트 박스, 오른쪽에 그에 대응하는 유형 결과 박스(01.svg와 동일 색상 매핑)를 화살표로 연결. 텍스트는 초안 문장 그대로만 사용:
  - "정보를 물어보고 답만 들으면 되는 일" → 챗봇형
  - "초안을 거들어줄 손이 필요한 문서 작업" → 코파일럿형
  - "규칙이 명확한 반복 업무" → 워크플로우 자동화
  - "조건에 따라 스스로 판단해 실행해야 하는 일" → 독립 에이전트
  하단에 작게 "한 가지만 골라 전체에 적용하지 않기 — 업무별로 다르게 배치"라는 보조 문구(초안 문장 요지 그대로) 추가
- 비율/viewBox: `0 0 1200 800`
- alt 텍스트: 업무 성격에 따라 챗봇, 코파일럿, 워크플로우 자동화, 독립 에이전트 중 알맞은 유형을 고르는 분기 흐름도
- 파일명: 03.svg
